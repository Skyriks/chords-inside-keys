This project covers chords within musical keys. A chord can keep the same notes
but have a different role when the key changes. For example, C major contains
C, E and G. It is the tonic chord in C major and the subdominant chord in G major.
The knowledge base separates the chord from its role in a key so both facts can
be represented without conflict.

A music learning tool could use this model to explain chord notes, find chords
in a key, and show how their roles change. The first version covers major keys,
natural minor keys and major, minor and diminished triads. It leaves out rhythm,
octaves, inversions and changes of key within a piece. The competency questions
below guide which facts and relations the model needs.
